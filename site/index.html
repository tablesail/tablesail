01 — QUERY, BEAUTIFULLY

Write SQL like you mean it.

Syntax highlighting and schema-aware autocomplete. Run the statement under the cursor or the whole script, and open or save .sql files.

-- Find your highest-value customers
SELECT name, SUM(orders.total) AS lifetime_value
FROM customers
JOIN orders USING (customer_id)
GROUP BY name ORDER BY lifetime_value DESC;

MORE UNDER THE HOOD

Everything a database client needs.

Connect from a URL

Paste a postgres://, mysql://, mongodb:// or SQLite connection URL and the form fills itself in.

SSH tunnels

Reach private databases through a bastion host, with a key file, the SSH agent or a password.

OS keychain

Passwords are stored in the macOS Keychain, Windows Credential Manager or the Linux secret service, never in plain text.

Environment tags

Colour connections as local, staging or production so you never mistake one for the other.

Stream, export, import

Export CSV, JSON, JSON Lines or SQL INSERTs straight from the cursor. Import CSV files and SQL dumps.

Copy and paste rows

Copy selected rows as INSERT statements, JSON or Markdown, and paste rows into the grid.

Table admin

Drop, truncate and rename tables from the sidebar, with the SQL previewed first.

Query console

See every statement TableSail sends to your server, so nothing runs behind your back.

AI assistant

Optional. Ask for SQL in plain English with your own Anthropic API key, which stays in the keychain.

GOOD TO KNOW

A few things
worth knowing.

Clear answers while the project takes shape.

Is TableSail free?

Yes. TableSail is free and MIT-licensed, with no paid tier, licence keys or nag screens.

Which databases does it support?

PostgreSQL, MySQL, MariaDB, SQLite and MongoDB. Each engine is tested against a live server.

Is TableSail a TablePlus alternative?

It aims at the same job, a fast database client that feels native, but it is free and open source. TableSail is an independent project and is not affiliated with TablePlus.

Is it ready for production data?

It is early alpha. Be careful with production databases: use a read-only user where you can, and review the SQL preview before you commit an edit.

Does TableSail collect any data?

No telemetry or analytics. The app talks to your databases, and to the Anthropic API only if you switch on the AI assistant with your own key. The About dialog can check GitHub for updates.

Where do I download it?

From the GitHub releases page, or build it from source. See the Download section above.

Can I try the interface without installing?

Yes. The interactive preview above lets you switch sample tables, inspect rows, filter results and run simulated SELECT queries. It does not connect to a database.
