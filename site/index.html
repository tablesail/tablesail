macOS, Windows and Linux

Built for speed

These are our design targets, not benchmark results.

< 100 ms

Built to show the first row in under 100 ms.

60 fps

Built to scroll a million rows at 60 frames per second.

Bounded

Built to keep memory bounded, however large the result.

Cancel

Every long operation is built to be cancellable, and nothing should block the UI.

Engines

  • PostgreSQL
  • MySQL
  • MariaDB
  • SQLite
  • MongoDB

Features

Virtualized grid

Only visible rows are rendered, so huge tables stay smooth.

SQL editor

Syntax highlighting and autocomplete for your schema.

Safe editing

Review the exact SQL preview before any change is applied.

SSH tunnels

Reach private databases through a bastion host.

Keychain

Passwords are stored in your operating system keychain.

Environment colours

Tint connections so production never looks like staging.

Streaming export

Export large result sets as they stream, without loading them into memory.
